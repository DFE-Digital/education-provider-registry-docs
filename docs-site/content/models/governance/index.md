# Governance

This section contains the machine-readable governance subdomain artefacts.

## Artefacts

| Artefact | Format | What it does |
| --- | --- | --- |
| [Vocabulary](./vocabulary/) | SKOS | Defines the provisional governance nouns, preferred labels and working definitions |
| [Taxonomy](./taxonomy/) | SKOS | Defines controlled governance classifications such as participant capacity, appointment type, appointing party, role, lifecycle status and historical provenance |
| [Ontology](./ontology/) | OWL 2 | Defines governance classes, object properties and named individuals - governance people, governance bodies, appointments, role types, appointing bodies, appointment basis, legal capacities, constitutions and compliance/assurance records - generated by WIDOCO from the source TTL |
| [Ontology graph viewer](./ontology/webvowl/) | WebVOWL | Interactive force-directed graph of the governance ontology - explore classes and properties visually |

The governance vocabulary remains flat. Taxonomic classification is held separately in `governance-taxonomy.ttl`, so a concept can occur in more than one facet without implying a single inheritance hierarchy. The ontology reuses the same `gov:` URIs as classes and named individuals (OWL 2 punning), and is a deliberately separate model from the governance classes already present in the main [Education Provider Registry ontology](../../ontology/) - it is expected to eventually supersede them, but not until it has been refined and reconciled against production data. The source files are [`models/governance/governance-vocabulary.ttl`](https://github.com/DFE-Digital/education-provider-registry-docs/blob/main/models/governance/governance-vocabulary.ttl), [`models/governance/governance-taxonomy.ttl`](https://github.com/DFE-Digital/education-provider-registry-docs/blob/main/models/governance/governance-taxonomy.ttl) and [`models/governance/governance-ontology.ttl`](https://github.com/DFE-Digital/education-provider-registry-docs/blob/main/models/governance/governance-ontology.ttl).

Vocabulary and Taxonomy above sit behind the site's password gate, like the rest of this section. Ontology and Ontology graph viewer do not - WIDOCO and WebVOWL load their content via client-side requests to sibling files, which the password gate cannot support page-by-page, so these two pages are public, matching the main ontology documentation.
