# Establishment Ontology — worked examples

Worked examples mapping real-world GIAS establishment records onto `establishment-ontology.ttl` (`est:`/`esto:`), following the same pattern as the [governance worked examples](../../governance/worked-examples/). Each example draws on a real GIAS extract - not synthetic data - and is explicit about where the ontology fits the evidence cleanly and where it doesn't (yet).

| Example | Establishment or trust | Type |
|---|---|---|
