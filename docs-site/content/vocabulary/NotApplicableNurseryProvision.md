## Definition

A classification value indicating that a nursery provision classification does not apply to this type of establishment.

## Scope Notes

- Used for establishment types where nursery provision is conceptually inapplicable, such as secondary schools, sixth-form colleges, or further education institutions. Distinct from NoNurseryClasses, which applies to establishment types where the field is relevant but no nursery classes are provided.
