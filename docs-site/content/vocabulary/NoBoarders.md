## Definition

A boarding-provision value indicating that the establishment does not accommodate any pupils as boarders.

## Scope Notes

- Applies to schools for which the boarding provision field is applicable (i.e. maintained or independent schools), but where no boarding is offered. Distinct from a NotApplicable value, which would indicate the field is irrelevant to the establishment type.
