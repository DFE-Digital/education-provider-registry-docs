## Definition

An organisation or governance structure to which one or more establishments belong. Includes academy trusts, federations and children's centre groups.

## Scope Notes

- Distinct from the accountability relationship, which records which body is legally responsible for the establishment. Academy trusts are both establishment groups and accountability bodies simultaneously.
