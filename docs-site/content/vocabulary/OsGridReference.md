## Definition

The Ordnance Survey National Grid reference for the establishment's location, expressed as easting and northing values in the OSGB36 coordinate reference system. Both values are displayed on the establishment location tab in GIAS.

## Scope Notes

- Derived from the establishment's postcode. Enables map display and proximity calculations. The easting and northing are displayed as separate fields in the GIAS UI.
