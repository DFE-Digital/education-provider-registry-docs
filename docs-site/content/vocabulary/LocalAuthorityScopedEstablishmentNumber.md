## Definition

The pairing of a local authority code with an establishment number that together form a meaningful local identifier. Neither component is globally unique in isolation.

## Scope Notes

- A single establishment identity may carry both a current and a previous scoped establishment number, distinguished by an identifier role. This models academy conversion, rebanding and other scenarios where an establishment acquires a new LA context or number.
