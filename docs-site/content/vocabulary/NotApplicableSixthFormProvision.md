## Definition

A classification value indicating that a sixth-form provision classification does not apply to this type of establishment.

## Scope Notes

- Used for establishment types where sixth-form provision is conceptually inapplicable, such as primary schools, nursery schools, or pupil referral units. Distinct from NoSixthForm, which applies to establishment types where the field is relevant but no sixth form is provided.
