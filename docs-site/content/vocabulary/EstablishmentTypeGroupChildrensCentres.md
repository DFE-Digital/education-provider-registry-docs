## Definition

The establishment type group for children's centres, which deliver integrated early-childhood services under the statutory framework introduced by the Childcare Act 2006.

## Scope Notes

- Contains 1 active EPR type: Children's centre (type code 47). Children's centre linked site (type code 48) is retained as a Legacy concept for historical GIAS data but is not modelled as an EPR establishment type — linked sites are represented as epr:Site instances attached to a children's centre establishment. The statutory duty on local authorities to secure sufficient children's centre provision was removed by the Children and Families Act 2014; many centres have since closed or merged.
