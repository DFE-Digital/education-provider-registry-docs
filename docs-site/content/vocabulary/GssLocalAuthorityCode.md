## Definition

The ONS Government Statistical Service code for the local authority in whose area the establishment is located. A machine-readable identifier (for example E08000007 for Stockport) used for cross-referencing with ONS statistical datasets and published geographies. Displayed on the establishment location tab in GIAS.
