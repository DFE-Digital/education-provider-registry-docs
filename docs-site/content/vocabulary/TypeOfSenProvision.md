## Definition

Up to four types of special educational needs for which the establishment provides specialist support, drawn from the need types defined in the SEND Code of Practice 2015 (such as Autism, Hearing impairment, Social emotional and mental health).

## Scope Notes

- Shown for maintained and academy schools. Independent and non-maintained special schools instead show special pupil counts. The database stores up to four SEN types per establishment.
