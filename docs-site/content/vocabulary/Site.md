## Definition

A physical location at which an establishment operates. A site has a name, a UPRN, OS grid coordinates, and a postal address. Distinct from an address — a site is a physical place where education is delivered; an address locates an entity for administrative and correspondence purposes.

## Scope Notes

- In GIAS, the principal site is defined by the main establishment address fields (siteName, Street, Locality, Address3, Town, Postcode, UPRN). Additional sites are held in EstablishmentAdditionalAddresses, restricted to three establishment types: Other independent school, Other independent special school, Non-maintained special school.
