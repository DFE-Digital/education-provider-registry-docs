## Definition

The SEN need type for which the establishment's resourced provision is designated. Resourced provision is a unit within a mainstream school providing specialist SEN support funded by the local authority, serving pupils who are not in specialist provision full-time.

## Scope Notes

- The database field name uses Reserved rather than Resourced, a legacy naming difference. The UI label uses resourced.
